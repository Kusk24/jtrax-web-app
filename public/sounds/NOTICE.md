# Board sounds

Original to JTrax. Every file here is synthesised by `scripts/make-sounds.mjs`
— no recordings, and nothing taken from chess.com, Lichess or any other site.
Regenerate them with:

    node scripts/make-sounds.mjs

The script is seeded, so it reproduces these files byte for byte. To change a
sound, change the script and regenerate; do not edit the `.wav` files.
